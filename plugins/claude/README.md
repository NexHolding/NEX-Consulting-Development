Claude Plugin (Platzhalter)

Dieses Verzeichnis enthält die Konfigurations-Hinweise für das Claude-Plugin.

Konfiguration:
- API_KEY in `.env` speichern: `CLAUDE_API_KEY=...`
- Implementiere einen Adapter in `plugins/claude/` für Anfragen und Rate-Limiting.

Wenn Du mir den API-Key gibst oder möchtest, dass ich die Verbindung mittels CLI/Token herstelle, sag Bescheid.
